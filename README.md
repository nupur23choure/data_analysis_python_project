# Gurgaon Real Estate Market Analysis

## 📌 Project Overview

This project analyzes residential real estate data from Gurgaon to identify
property price trends, locality-wise pricing patterns, and factors affecting
property prices.

The objective is to transform raw real estate data into meaningful,
data-driven insights that can support buyers, sellers, and real estate
business decisions.

---

## 🎯 Business Objective

The analysis focuses on understanding:

- Which localities have the highest average property prices?
- Which localities have the highest average price per square foot?
- How does property area affect property price?
- How does BHK configuration affect pricing?
- Which localities offer relatively higher or lower property rates?
- What patterns and trends can be identified from the available data?

💡 Key Insights

Some important findings from the analysis include:

Baliawas has the highest average property price in the dataset.
Sector 42 contains the highest-priced individual property in the dataset.
Property prices generally increase with larger property areas, although the relationship is not perfectly linear.
Property rates vary significantly across Gurgaon localities.
BHK configuration also shows differences in property pricing.
